Functions FAQ
=============

Q: What keyword defines a function in Python?
A: def — e.g. `def greet(name): ...`

Q: What does a function return if it has no return statement?
A: None.

Q: What's the difference between a parameter and an argument?
A: A parameter is the name listed in the function's definition. An argument
is the actual value you pass in when you call the function.

Q: Can a function return more than one value?
A: Yes — Python lets you return multiple values separated by commas, which
are packed into a tuple, e.g. `return x, y`.
